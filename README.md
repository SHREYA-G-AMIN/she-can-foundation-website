# She Can Foundation Website

A responsive website created for the She Can Foundation internship selection task using HTML, CSS, and JavaScript.

## Features

- Home section
- About section
- NGO introduction
- Volunteer / Join Us button
- Footer section
- Dark mode toggle
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

she-can-foundation-website/
│── index.html
│── style.css
│── script.js
│── README.md

## Purpose

This project was created as part of the internship selection task for She Can Foundation.

The website highlights the foundation’s mission of empowering girls and women through awareness, education, and support.
